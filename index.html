What data am I looking at?

  • Each spreadsheet row is one respondent. We call that row a response.
  • Each question column holds that respondent’s answer. One cell is one answer, so one response can supply up to five answers.
  • The dashboard adds counts, percentages, shorter headings, category labels and themes. It does not invent, correct or rewrite any original answer.
  • Administrative and scoring fields (timestamps, name, email, points, quiz feedback) are left out. The ID column is kept so you can trace each answer back to its row.
  • A missing answer is a blank cell in one of the five question columns. Blank points or feedback cells are not counted as missing and are never treated as zero scores.
  • How to explore: read a chart’s question, click a bar, and the page jumps to the matching original answers in the response table.

    Method

    How answers become themes

    Questions 2 and 5 are free-text. To chart them, the dashboard sorts each answer into topic labels using simple keyword rules. Here is exactly how that works.

    1. A theme is a topic label added by the dashboard. It is not a survey question and not a column in the spreadsheet.
    2. Theme grouping applies only to the written answers to Question 2 (everyday reliance) and Question 5 (business considerations).
    3. Each theme has a list of keywords or phrases.
    4. An answer matches a theme if it contains at least one listed phrase, ignoring capital letters. A phrase must start at the beginning of a word but may continue into a longer word: translat matches “Translating” and “translation”, and law matches “laws” but not “flawed”.
    5. Each answer counts once per matching theme, even if several keywords from that theme appear in it.
    6. One answer can match several themes, so theme percentages can add up to more than 100%.
    7. A theme percentage is its matching-answer count divided by all selected responses. Responses with a missing answer stay in the denominator, so missing answers lower every theme’s percentage. They are shown as their own bar.
    8. Unmatched means the cell had an answer but it matched no theme keywords. Missing answer means the question cell was empty.
    9. Keyword matching does not understand meaning, context or negation. “Not secure” still matches secur.
    10. These are provisional groupings for class discussion. They are not a definitive qualitative analysis and not a judgement of whether an answer is correct.
    Inspect & adjust classification rules

    Each box lists the keywords for one theme, separated by commas. To add a word or phrase, type a comma and then the phrase. To remove one, delete it together with its comma. Then click Apply theme rules. Charts, examples, the worked example, observations and any active theme filter are recalculated. The original answers and the Excel workbook do not change. Restore defaults puts back the original keyword lists. Edits are kept only while this page is open; reloading the page restores the defaults.

    Fixed rules for Questions 3 and 4

    Privacy concern and AI preference answers are sorted with a separate set of fixed rules that cannot be edited on this page. They differ from the theme rules in one important way: each answer gets exactly one category. Rules are checked top to bottom and the first match wins, so the order matters. For example, uncertainty is checked first so that “I am unsure because I do not know where my data goes” is not counted as “not concerned”. Matching ignores capital letters and uses the same start-of-word rule as above. An answer that matches no rule goes to Other / review; a blank cell goes to Missing answer.
